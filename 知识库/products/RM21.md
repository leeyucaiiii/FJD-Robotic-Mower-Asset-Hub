# FJD RM21 知识页

## 定位摘要
- 一句话定位：一机多用，开启草坪护理的全能时代。
- 产品分类：多功能平台型草坪机器人（基于单页与官网文案推断）
- 主要场景：运动场、高尔夫球场、果园、草皮农场
- 描述摘要：RM21 是一款多功能机器人平台，通过快速更换机具即可实现割草、划线、集草、高尔夫捡球等多项作业。一机多能、灵活切换，适用于运动场、高尔夫球场、果园、草皮农场等多种场景，高效且具高性价比。

## 核心卖点
- 智能路径规划 / 设置需要工作的区域，让设备自动规划您目标的最佳路径。
- 多地块管理 / 一次任务涵盖多个区域，无论是连片高尔夫球场或大型运动场，都能轻松掌控
- 编队作业 / 云端任务下发，支持多机协同作业，快速完成大面积任务不再是难题。
- APP远程监控 / 随时随地查看状态、设定任务，真正实现智能养护新体验。
- 无惧RTK信号干扰 / RTK&LiDAR融合导航技术，轻松实现树下等RTK信号具有挑战性的区域作业。
- 多重安全保障 / 360°激光雷达实时环境监测和前后物理防撞，确保作业无忧。

## 关键参数
- 72-hour max mowing area: / Fast charging mode: 108,000㎡ (26.7 acres) / Standard charging mode: 93,600㎡ (23.1 acres)
- Max mowing area per charge: 12,000㎡ / 3 acres
- Cutting height: 20–127 mm / 0.8–5 in.
- Cutting width: 635 mm / 25 in.
- Max climbing ability: 20°
- Recommended working slope: 15°
- IP rating: IPX4
- Battery capacity: 4 kWh
