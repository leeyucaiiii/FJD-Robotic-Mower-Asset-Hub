# FJD RCM01 知识页

## 定位摘要
- 一句话定位：每一叶草都完美，每一个角落都自主。
- 产品分类：高端滚刀式专业草坪机器人（基于单页与官网文案推断）
- 主要场景：高尔夫球场、体育场 premium turf
- 描述摘要：专为高端草坪场景打造的无人滚刀割草机器人，以滚刀式精剪技术实现赛事级草坪修剪品质。融合RTK与激光雷达导航，无惧遮挡，精准自主作业。全程无人操作、远程管理，为高尔夫与体育场带来更高效、更安全、更低成本的草坪养护方式。

## 核心卖点
- 一次扫描，全盘自动化 / 使用 FJD P2 扫描仪数分钟内即可完成测绘——无需手动驾驶。创建可在整个车队共享的数字资产。
- 夜间作业 / 可于夜间无人作业，增加高尔夫球场白天的运营时长
- 无惧树下作业 / 采用RTK技术&激光雷达融合导航系统，即使在树荫或遮挡区域，也能保持稳定的作业精度
- 多地块管理 / 支持多个高尔夫球球道区域同时作业，任务完成后自动前往下一场地，连续作业无缝衔接
- 一站式数字化调度 / 通过专用 APP 远程操控设备、设定割草计划，并查看实时与历史状态。 / 联动 Greenmaster 平台，实现作业地图与设备数据的一体化管理，构建高效可视化的智慧草坪管理体系。

## 关键参数
- Max mowing area* / 72h Maximum coverage 28,800㎡ (7 acres) / 24h Maximum coverage 86,400㎡ (21.3 acres) / *Calculated based on 24-hour operation. Actual coverage depends on user working hours.
- Max mowing area per charge / 20,000㎡ (5 acres)
- Cutting height / 7-44 mm / 0.3-1.7 in.
- Cutting width / 686 mm / 27 in.
- Max climbing ability / 20°
- Max mowing slope / 15°
- Boundary type / Virtual wire
- Connectivity / 4G, Wireless Connectivity
