# FJD FL3000 知识页

## 定位摘要
- 一句话定位：See Further. Mow Smarter.
- 产品分类：家用 / 轻商用 LiDAR 智能割草机（基于现有文案推断）
- 主要场景：家庭庭院
- 描述摘要：The FJD FL3000 is a smart, autonomous robotic mower powered by LiDAR and vision technology. It can avoid obstacles, and deliver a precise, even cut—without buried wires or complex setup.

## 核心卖点
- 无埋线・无基站 / 彻底告别繁琐铺线与基站搭建，无惧卫星信号遮挡，节省施工时间与费用
- 自动探索边界 / 将机器人放置在草坪上，即可自动识别边界并完成区域建图。 / *适用于草地与石板、围栏等非草地区域分界明显的场景。
- LiDAR&视觉导航，信号无忧 / 无需RTK，无惧树木遮挡、高墙阻隔与信号盲区，稳定可靠，全天候智能作业保障
- 自动绕障 / 实时动态避障，路径自适应调整 / 可调节避障高度，匹配你的庭院需求 / 自定义避障高度，既精准避让又不影响割草效率。
- 全流程掌控，只需一个App / APP一键开始，并实时查看状态
- 智能路径规划 / 路径智能规划，复杂地形也能高效割草

## 关键参数
- Recommended mowing area：3000 m² (0.75 acre)
- Cutting height: / 20–60 mm / 0.8–2.4 in. (Standard) / 10–50 mm / 0.4–2.0 in. (Standard with adapter) / 40–80 mm / 1.6–3.2 in. (High-cut version)
- Cutting width: 260 mm / 10 in.
- Max climbing ability: 33° (65%)
- Max mowing slope: 25° (47%)
- Boundary type: Virtual wire
- Connectivity: 4G, Wireless Connectivity
- IP rating: / Mower: IPX5 / Charging Station: IP65
