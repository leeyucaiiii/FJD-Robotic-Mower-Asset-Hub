# FJD Titan 知识页

## 定位摘要
- 一句话定位：二合一顶尖草坪养护，亲民价格。
- 产品分类：大型场地旗舰级割草 / 划线二合一平台（基于单页与官网文案推断）
- 主要场景：高尔夫球场、运动场、公共绿地
- 描述摘要：FJD Titan 由三层导向系统和智能车队管理驱动，为世界级高尔夫球场和运动场提供卓越的割草性能。它作为一体化的二合一解决方案，配备了划线套件，以确保出色的标线精度。

## 核心卖点
- 可调节切割高度 / 通过 App 在 10–100 毫米范围内调节切割高度，以匹配草坪类型和季节。
- 宽幅高效 / 730 毫米的切割宽度可实现高日产量——每天高达 36,000 平方米。
- 三层导航系统 / 双 RTK GNSS、LiDAR 和视觉技术协同工作，实现稳定的定位和避障。
- 一次扫描，多次复用 / 使用 FJD P2 扫描仪，在几分钟内完成地图绘制——无需手动驾驶。创建可在整个车队中共享的数字资产。
- 多区域管理 / 自动化的多区域割草，在任务区域之间实现无缝切换。
- 配合划线套件，Titan在运动场上实现了卓越的划线精度和效率，大幅减少了劳动力和油漆使用。
